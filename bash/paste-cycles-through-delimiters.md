# `paste -d` は区切り文字を1文字ずつ循環して使う

`paste -sd', ' -` で「カンマ+空白」で連結されると思っていたが、そうならない。

```sh
$ printf 'a\nb\nc\nd\n' | paste -sd', ' -
a,b c,d
```

`-d` に渡した文字列は**区切り文字のリスト**として解釈され、
`,` → 空白 → `,` → 空白 と**循環して1文字ずつ使われる**。
「区切り文字列」ではない。

## 実際に踏んだ形

YAML の配列を組み立てていて、こうなった。

```
topics: ["bash","git" "shell","macos"]
```

2番目と3番目の間だけカンマが無い。**YAML としては壊れているが、
パースするまで気づかない**。生成物を目で読まなければ見逃していた。

## 正しいやり方

1文字で連結してから置換する。

```sh
$ printf 'a\nb\nc\nd\n' | paste -sd, - | sed 's/,/, /g'
a, b, c, d
```

`tr '\n' ','` でも同じ問題は起きない（`tr` は1対1変換なので）。

検証: macOS 14 / BSD paste
