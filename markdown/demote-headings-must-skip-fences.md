# Markdown の見出しを繰り下げるとき、コードブロックの中を触ってはいけない

複数の Markdown を1つの記事に束ねるとき、各ファイルの見出しを1段下げたくなる。
素朴にはこうする。

```sh
sed 's/^\(#\{1,5\}\) /#\1 /'
```

これは**コードブロック内のシェルコメントも見出しに変えてしまう。**

````
```sh
# 壊れる: NUL が失われる     ← これが「## 壊れる:」になる
```
````

## フェンスの状態を持つ

行頭の ``` でフェンスの内外をトグルし、外側だけ処理する。

```sh
awk '
  /^```/            { fence = !fence; print; next }
  !fence && /^#{1,5} / { print "#" $0; next }
                    { print }
'
```

## 気づきにくい理由

コードブロックの中身は「動かして確かめる」対象ではないので、
壊れても実行時エラーにならない。**レンダリング結果を目で見るまで分からない。**

同じ理由で、コードブロック内の行に対する一括置換は全般に危ない
（インデント調整、パス書き換え、変数名の一括リネームなど）。

検証: 2026-08-22 / awk (BSD)
