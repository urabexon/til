# Zenn に投稿用の公開 API は無い。GitHub 連携がそれにあたる

自動投稿を作ろうとして API を探したが、**Zenn は記事投稿用の公開 API を提供していない。**

| 種類 | 状況 |
|---|---|
| 投稿用の公式 API | **無い** |
| GitHub 連携 | あり。**これが唯一の公式な自動投稿手段** |
| Zenn CLI | あり。ローカルのプレビューと雛形生成のみ。**投稿はしない** |
| 記事取得の「隠し API」 | 非公式に存在するが仕様非公開・読み取り専用・予告なく壊れる |

つまり **`git push` が publish に相当する**。

```
articles/ に .md を置く → push → Zenn が自動デプロイ
```

Qiita や dev.to には投稿用の REST API があるので、同じ感覚で探すと見つからずに迷う。
Zenn は記事の正本を GitHub 側に置かせる設計を選んでいる。

## 実装への影響

自動化の構造は API があってもなくてもほぼ同じで、
**変わるのは最後の1手が `git push` か `curl -X POST` かだけ**。
素材を集めて束ねて frontmatter を組む部分は共通なので、
「API が無いから作れない」ということにはならない。
