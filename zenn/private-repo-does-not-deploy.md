# Zenn の GitHub 連携は private リポジトリだと記事が出てこない

GitHub App の権限も付与し、Zenn 側でリポジトリも選択し、push も通っている。
それでもダッシュボードに記事が現れない。**エラーも警告も出ない。**

リポジトリを public に切り替えた瞬間に、下書きが現れた。

可視性以外は何も変えていないので、原因は private であること自体とみてよい。

## 気づきにくい理由

失敗が失敗の形をしていない。

- GitHub App の権限付与は成功する
- Zenn のリポジトリ選択にも出てくる（ここで選べるので「繋がった」と思う）
- push もエラーにならない
- ただ、何も起きない

「反映が遅いのだろう」と待ってしまうのが一番時間を溶かす。

## そもそも private にする意味が薄い

Zenn に記事を出す時点で内容は公開される。
リポジトリを private にして守れるのは「未公開の下書き」だけだが、
それは `published: false` と、`articles/` の外（`drafts/` など）に置くことで達成できる。
Zenn は `articles/` と `books/` しか読まない。

## 切り分けの順番

出てこないときに見る順。

1. **リポジトリが public か**
2. Zenn 側の設定で**同期ブランチ**が正しいか（既定が `master` のことがある）
3. `articles/` が**リポジトリ直下**にあるか
4. ファイル名が**スラッグ規則**を満たすか（`a-z0-9_-` の 12〜50 文字）
5. `published: false` の記事は「公開記事一覧」には出ない。**記事の管理**の方を見る
